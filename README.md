
# Freelance Site

Website portofolio dan layanan jasa pembuatan website.

## Project Purpose

Proyek ini dibuat sebagai media latihan untuk meningkatkan kemampuan frontend development sekaligus membangun website portofolio jasa freelance.

## Technologies

- HTML5
- Tailwind CSS
- JavaScript (Vanilla)

## Development Rules

- Tidak menggunakan React, Vue, atau framework JavaScript lainnya.
- Tidak menggunakan library JavaScript.
- Seluruh logika interaktif ditulis menggunakan JavaScript murni.
